# 🛡️ Manual Testing Project

## 📖 Project Overview

This repository contains all the manual testing artifacts for the **shop.shajgoj.com** website.

The objective of this project is to verify the application's **functionality, usability, reliability, compatibility, and overall quality** through comprehensive manual testing.

---

## 📌 Project Information

**Website:** shop.shajgoj.com  
**Project Type:** Manual Testing  
**Testing Approach:** Black-Box Testing

---

## 📂 Modules Tested

- 🔍 Product Search
- 🎛️ Product Filter
- 📦 Product Details
- 🛒 Shopping Cart
- 💳 Checkout
- ✅ Order Confirmation

---

## 🧪 Testing Scope

- ✅ Functional Testing
- 🎨 UI Testing
- 👨‍💻 Usability Testing
- 📏 Boundary Value Analysis

- 🌐 Compatibility Testing

## 🚀 How to Run This Project

1. 📥 Clone this repository.
2. 📂 Open the project repository.
3. 📄 Open the required test documents.
4. ▶️ Execute the documented test cases manually.
5. 📝 Record the actual results.
6. 🐞 Log defects for failed test cases.
7. 📊 Update the Test Summary Report.
8. 📈 Update the relevant test metrics and RTM.
